## ✨ Features

* **Dynamic Glass Aesthetics:** Sleek macOS Tahoe-inspired translucency and blur effects.
* **Dual Theme Support:** Separate, dedicated configurations for both **Dark Mode** and **Light Mode**.
* **Redesigned Dock Background:** Custom layout and spacing calibrated for **MyDockFinder v1.9.9.7**.
* **100% Free:** No Steam Workshop subscription required. Just download, extract, and apply.

> **⚠️ Note on Icons:** The included icon settings are optimized for Light Mode. To complete the full Tahoe look, pair this theme with your preferred macOS Tahoe icon pack!

## 🚀 How to Install

1. **Download the Theme:** Go to the [**Releases Page**](https://github.com/jolli-tec/jolly-molly-tahoe-theme-for-mydockfinder/releases) and download the latest `.zip` archive under **Assets**.
2. **Extract the Files:** Unzip the downloaded package to a temporary folder.
3. **Locate Your MyDockFinder `themes` Folder:** Open File Explorer and navigate to where you extracted MyDockFinder, for example:
   * `C:\MyDockFinder_2024\themes`
   * `C:\Users\[YourUsername]\Downloads\MyDockFinder_2024\themes`
4. **Copy & Paste:** Copy the extracted **Jolly Molly** theme folder(s) into the `themes` directory.
5. **Apply the Theme:** Open **MyDockFinder Preferences**, go to the themes section, and select either the **utilimg (Dark)** or **jolly molly v2 (Light)** Jolly Molly preset.
